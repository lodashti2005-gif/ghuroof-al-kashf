# إصلاح تعليق الاستجواب الجماعي

## الهدف
إصلاح السبب الفعلي لتعليق مرحلة الاستجواب مع بقاء التصميم والقضية والمؤقت والتوتر والأدلة دون تغيير.

## التنفيذ
- فصل حالة انتظار طلب الذكاء الاصطناعي محليًا لكل جهاز، مع مهلة زمنية وإلغاء آمن ورسالة فشل وزر إعادة المحاولة.
- منع أي طلب لاعب من كتابة حالة «يفكر» مشتركة تقفل أو تربك أجهزة بقية اللاعبين.
- جعل تحديثات حالة الغرفة ذرّية قدر الإمكان بدل استبدال كامل `rooms.state` من snapshots قديمة، لمنع ضياع رسائل متزامنة أو رجوع المؤقت/الأدوار للخلف.
- ضبط اشتراك Realtime ليكون قناة واحدة فقط لكل جلسة/غرفة، مع دمج refreshes المتزامنة ومنع حلقات الاستدعاء المتكررة.
- تثبيت session مستقلة لكل لاعب، وتنظيف سجل اللاعب عند الخروج أو إغلاق الصفحة، مع تحديث العدد لكل الأجهزة دون إعادة توزيع الأدوار أو تصفير الجولة.
- الحفاظ على الدور والحالة الحالية عند refresh/reconnect.

## التحقق
- فحص أخطاء المتصفح والشبكة بعد الإصلاح.
- تشغيل محاكاة حقيقية لستة لاعبين في Room ID واحد: دخول، توزيع أدوار، بدء الجولة، أسئلة متزامنة من عدة أجهزة، تبديل المشتبهين، والعودة لمسرح الجريمة.
- التأكد أن كل جهاز يبقى تفاعليًا، وعدد اللاعبين والحالة مشتركان ومتزامنان، وفشل/تأخر AI لا يترك spinner دائمًا.

## تفاصيل تقنية
- لا تغييرات بصرية أو محتوى جديد.
- أي تعديل قاعدة بيانات ضروري للتحديثات الذرّية سيتم عبر migration مع الصلاحيات والسياسات الحالية محفوظة.
